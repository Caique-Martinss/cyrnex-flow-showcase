# CYRNEX — Sistema de marca

## Decisão oficial

- **Marca-mãe:** CYRNEX
- **Assinatura / abreviação:** CRX
- **Produto SaaS atual:** CYRNEX FLOW
- **Serviços personalizados:** CYRNEX STUDIO
- **Produtos e experimentos:** CYRNEX LABS

O nome técnico anterior foi aposentado. A partir deste checkpoint, a identidade de produto e documentação deve usar **CYRNEX FLOW** e o monograma **CRX**.

## Identidade do produto atual

A interface existente permanece na identidade premium escura já estabilizada:

- background: `#090b0a`
- surface: `#121512`
- secondary: `#0f1210`
- strong: `#171815`
- text: `#f5f3ed`
- muted: `#a9aaa4`
- gold: `#d6a34b`

O preto/carvão é dominante; o dourado é usado como acento discreto.

## Exploração visual CYRNEX / CRX

As referências visuais oficiais preservadas em `docs/brand/assets/` incluem:

- conceito **Blackout Purple**: preto dominante + roxo/violeta profundo;
- conceito **Blackout Gold**: a identidade atual do produto, preto/carvão + dourado discreto.

Essas artes são referências de branding e poderão ser usadas em splash screen, loading screen, apresentação, site institucional e futura evolução do sistema visual.

## Regras de uso

- `CYRNEX` = empresa / marca principal.
- `CRX` = assinatura curta, monograma, favicon, ícone e contextos compactos.
- `CYRNEX FLOW` = nome comercial do SaaS de gestão.
- Não usar `CRX` como substituto obrigatório do nome falado; a leitura principal continua **Cyrnex**.
